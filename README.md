# Studies on Digital Speleometry

A project to study and apply computational geometry, linear algebra, and 3D point cloud processing to digital speleometry.

---

## Objectives

- Implement algorithms and data structures from scratch.
- Apply linear algebra through Python classes and algorithms.
- Process 3D point clouds using Python libraries.
- Develop a 3D point cloud viewer using JavaScript, HTML, and CSS.

---

## Project Structure

### Learning — Implementations from Scratch

- [Geometry](./Learning/geometry/): Point, vector, and matrix operations.
- [PCA](./Learning/PCA/): Principal Component Analysis implemented from scratch.
- [3D Point Cloud](./Learning/3dpointcloud/): Point cloud representation and operations.

---

### Point Cloud Processing

- [CloudPoints](./CloudPoints/): Point cloud processing using Python libraries and tools.
