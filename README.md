# Studies on Digital Speleometry

## Objectives:
1 - Reinforce fundamentals of algorithms and data structures by developing libraries from scratch
2 - Practice mathematical operations involving linear algebra concepts within class methods
3 - Process point clouds using Python libraries and tools
4 - Develop a viewer for 3D point cloud representations using JS and HTML/CSS
